# 風格：寫實時尚廣告風（Realistic Fashion Editorial）

貼在 prompt 最上方作為 STYLE 前綴。

## STYLE 前綴（英文，給圖像模型用）
```
STYLE: realistic fashion editorial photography — pure white seamless infinite backdrop, clean bright studio lighting, high-end fashion campaign look, photorealistic fabric texture.
```

## 中文版（給影片 prompt 用）
```
【风格】写实时尚广告风（fashion editorial），纯白无限背景（infinite white backdrop），登机牌滑入转场，一镜到底般的连贯丝滑感，色调干净明亮。9:16 竖屏。可无缝循环播放（seamless loop）。
```

## 特徵
- 純白無縫攝影棚背景（infinite white backdrop）
- 乾淨明亮打光、高階時尚廣告質感
- 真實布料/織紋質感
- 一鏡到底般連貫、鏡頭穩定不動
