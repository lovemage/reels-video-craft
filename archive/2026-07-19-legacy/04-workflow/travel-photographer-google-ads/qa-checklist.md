# 驗收清單

## 0. 首尾幀核准閘門

- [ ] 每國都有獨立首幀與尾幀，不共用其他國家的圖片。
- [ ] 八張圖片皆逐張展示給使用者檢查，沒有批次默認核准。
- [ ] 使用者核准版本已記錄於 `frame-approval.md`。
- [ ] 同一國家的首幀與尾幀皆為 `APPROVED` 後才開始生片。
- [ ] 被退回的圖片以新版本另存，未覆寫先前檢查版本。
- [ ] 沒有使用靜態人物推拉、縮放或 2.5D 效果冒充人物動態。

## A. 角色一致性

- [ ] 四段為同一張臉、同一低髮髻、同一灰藍襯衫與白 T。
- [ ] 橘棕背包、相機機身、鏡頭與背帶全程一致。
- [ ] 手指、手臂、肩帶、相機數量正常，沒有融接或穿模。
- [ ] 沒有多出第二位主角，也沒有突然換裝、戴帽或放下長髮。

## B. 場景與敘事

- [ ] 京都段可辨識朱紅千本鳥居，未混入東京塔或其他城市符號。
- [ ] 首爾段 N 首爾塔輪廓清楚，沒有混入東京晴空塔。
- [ ] 清邁段是尊重大象的遠距離拍攝；沒有騎乘、鎖鏈、表演或強迫互動。
- [ ] 舊金山段金門大橋結構、橋色與海灣環境合理。
- [ ] 四段各只有一個主動作，京都 2.55 秒、其餘約 2.2 秒內都能讀懂。
- [ ] 轉場統一為相機鏡片／快門閃白，沒有無關視覺噪音。

## C. 相機細節與聲音

- [ ] 拉背包拉鍊時，鏡頭固定在背包側袋與袋口，沒有提前漂到臉或地標。
- [ ] 取出相機時可看清握把、背帶與袋口的連續動作，沒有瞬間穿模。
- [ ] 轉盤每跨一格都有同步 click；手指沒有滑過卻無聲或沒碰到卻發聲。
- [ ] 對焦環旋轉時鏡頭鎖定刻紋；rack focus 完成後才拉回地標。
- [ ] 半按快門有短停、對焦馬達與確認 beep，之後才出現機械快門聲。
- [ ] 下一場環境音提前 4–6 幀進入；快門尾音延續 2–3 幀，轉場聽感連續。
- [ ] 京都→首爾鏡片遮幅、首爾→清邁閃白、清邁→舊金山前景 wipe、舊金山→照片牆閃白方向合理。
- [ ] 四個國家正式拍攝都切成全畫面觀景窗 POV，鏡頭分別正對伏見稻荷、N 首爾塔、大象、金門大橋。
- [ ] 只有京都開場從背包取相機；首爾、清邁、舊金山沒有重複開包或重新取機。
- [ ] 後三國轉場都先看見同一角色站在當地、相機已在手，再由舉機與鏡片遮幅自然進入 POV。
- [ ] 每次焦點皆由糊轉清；中央對焦框鎖定與 AF beep 同幀發生。
- [ ] 每次按下快門都有清楚「KATA／喀嚓」聲，之後立即呈現相同構圖的拍立得照片。
- [ ] 四張拍立得的下方白邊均以後製真字精確顯示 `aw-esim.com`，沒有模型亂碼、拼字錯誤或位置漂移。
