# 影片 Prompt — 四宮格放大縮回版 ★ 目前主方向

> **概念**：直接用現成的 **2×2 四宮格圖（`03-visual-draft/image.png`）當第一幀與唯一畫布**，鏡頭「逐格放大填滿→角色做動作→縮回四宮格全景」，四格輪流。
> 好處：登機牌與「aw-esim.com」文字已印在四宮格圖上（不會糊字）；插畫圖可過 Seedance 審核。

## 定案設定
| 項目 | 決定 |
|---|---|
| 第一幀 | 四宮格圖 `03-visual-draft/image.png`（左上 TOKYO／右上 SEOUL／左下 BANGKOK／右下 VIETNAM） |
| 生成方式 | 單段 AI 一鏡到底、以圖生片（first frame） |
| 鏡頭 | 會動（camera_fixed = false）：放大縮回，ease-in-out |
| 時長／畫幅 | 12 秒／**1:1 方形**（業主定案 B：方形放大縮回最順、不裁切） |
| 角色 | 同一位灰棕短髮旅客女孩，髮型全程不變 |

## 動畫流程
| 段落 | 格 | 角色動作（細化） |
|---|---|---|
| 0–3s | TOKYO 左上 | 從**左側走出** → 走過來看到登機牌 → **與登機牌自拍** |
| 3–6s | SEOUL 右上 | **從背包拿出相機** → 畫面切**相機視角** → 朝首爾塔拍風景照 |
| 6–9s | BANGKOK 左下 | 河邊有一艘**船**，**邊吃東西邊看船、吹涼風**、神情惬意 |
| 9–12s | VIETNAM 右下 | 天氣熱 → **戴上帽子** → 拿**扇子搧風**降溫 |

> 每段皆為「放大該格填滿 → 做動作 → 縮回四宮格全景」。

## 跑法（額度儲值後）
```bash
PROMPT_FILE=02-video-prompt/ad-video-grid-zoom.prompt.txt \
DURATION=12 ASPECT=1:1 CAMERA_FIXED=0 \
FIRST_FRAME=03-visual-draft/image.png \
python3 04-workflow/gen_video.py
```

## 畫幅：1:1 方形（定案）
四宮格圖本身是方形 1:1（1254×1254），影片也走 **1:1 方形**：全景四宮格與放大單格皆為方形、**不裁切**，放大縮回最順。首幀比例與輸出比例一致，無落差。

## ⚠ 已知風險（單段一鏡到底）
模型可能無法完美維持四宮格布局或精準執行「放大-動作-縮回」四輪。
**退路**：後製把放大/縮回運鏡在剪輯做，四格角色動作分別 AI 生成後嵌入。
